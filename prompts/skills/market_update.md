# Market Update Editorial Skill

Create a concise, evidence-led daily market briefing, not a generic forex lesson.

1. Establish the exact market date, timezone and data retrieval time.
2. Separate quoted prices and published releases from analyst interpretation.
3. Use source-provided price timestamps and distinguish spot, futures, CFD and index data.
4. Explain the main drivers only when retrieved evidence supports them. Check USD, yields,
   central-bank communication, major releases, liquidity/session context and relevant headlines.
5. Build a clear order: headline move, verified context, drivers, upcoming catalysts, scenarios,
   risk statement and viewer takeaway.
6. Do not invent XAUUSD spot prices from gold futures. Label GC=F as gold futures if used.
7. Do not manufacture probabilities, entries, targets, stop-losses or guarantees.
8. Do not frame a scenario as a certainty or personalise financial advice.
9. Use a newsroom visual language: real market-related footage, editorial data cards, event
   timelines, maps when relevant, and clean source-labelled charts.
10. Use IFXTrades branding only when explicitly requested in the current Telegram message.
